# StateHelper

Публичные выпуски справочника GTA5RP для Windows x64.

[Скачать StateHelper-Setup.exe](https://github.com/DominicRomanovNorris/GTA5RP_assist/releases/latest/download/StateHelper-Setup.exe)

Глобальный бинд по умолчанию: Ctrl + Space. Настройки позволяют изменить бинд и автозапуск. Правила и законы всех 13 серверов, Wiki, карта и Changelog доступны в приложении.

При первом запуске прочитайте политики и инструкцию. Удаление: Uninstall.exe с выбором сохранения настроек.

Исходники и сборка находятся в закрытом репозитории разработчика. Здесь опубликованы готовые установщики, portable-файлы и база; автообновление использует этот репозиторий.

Контакт: Discord **dominic9090**, студия [SFC Dev](https://discord.gg/RZ3kJJGntS).

[Счётчик скачиваний](https://api.github.com/repos/DominicRomanovNorris/GTA5RP_assist/releases/latest): поле download_count у StateHelper-Setup.exe. Счётчики включают повторные загрузки и автообновления. После переноса репозитория счётчики начались заново; предыдущие значения сохранены в downloads-before-migration.json.
