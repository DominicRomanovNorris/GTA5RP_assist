# StateHelper

Помощник для игроков GTA5RP: правила и законы 13 серверов, GTA5RP Wiki и разбор игровых ситуаций с Gemini.

[Скачать установщик StateHelper-Setup.exe](https://github.com/DominicRomanovNorris/GTA5RP_assist/releases/latest/download/StateHelper-Setup.exe) · [Portable ZIP](https://github.com/DominicRomanovNorris/GTA5RP_assist/releases/latest/download/StateHelper-Portable-win-x64.zip) · [История выпусков](https://github.com/DominicRomanovNorris/GTA5RP_assist/releases)

Windows x64. Установщик включает .NET и при необходимости устанавливает Microsoft WebView2. Обновления доступны автоматически из этого репозитория; старые адреса сохранены. Фирменный Uninstall.exe позволяет сохранить настройки для переустановки или удалить их полностью.

## Как пользоваться

- Ctrl + Space открывает и скрывает окно поверх игры; бинд можно изменить в настройках с шестерёнкой.
- Выберите «Правила» или «Закон» и свой сервер. Начните вводить запрос для локального поиска. Например: «Статья 12.8 УК».
- Опишите игровую ситуацию и нажмите Enter для разбора с Gemini. Перед первым запросом требуется отдельное согласие; вопрос, выбранный сервер и публичные выдержки отправляются через Cloudflare в Google. Ключа Gemini в приложении нет.
- Ответ появляется справа. Нажмите кнопку [S1] или другого источника, чтобы прочитать статью и проверить оригинал на форуме. При недостатке сведений помощник попросит уточнить обстоятельства. ИИ может ошибаться.
- Транспорт, карта, недвижимость и другие каталоги показывают настоящий GTA5RP Wiki внутри приложения. В Changelog есть история программы и вкладка Dev blog.

Локальный поиск работает без интернета. Для Wiki и Gemini требуется интернет. Скрытие окна отменяет ожидание ИИ и откладывает автоматические загрузки; Wiki приостановлена. Сервер ИИ ограничивает частоту и общее дневное число запросов. При лимите обычный поиск остаётся доступен.

При первом запуске прочитайте политику конфиденциальности, условия использования и обучение. Документы входят в установщик и доступны повторно в настройках. У функции Gemini есть возрастные и региональные ограничения Google; обычный поиск доступен без неё. В бесплатном режиме Gemini Google может использовать введённые данные для улучшения продуктов. Не вводите пароли или личные сведения.
